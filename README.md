# wwbakt-keyboard-shortcuts
This project contains a a thin javascript layer providing keyboard shortcuts to the LIMS wwbakt.

Current shortcuts are:

Alt+1           Problemliste


Alt+2           Obsliste

  Alt+T           Tag prøve på OBS liste med dine initialer
  
  Shift+Alt+T     Skift initialer til OBS liste
  
  Alt+X           Fjern markerede


Alt+P           Patientfane

  Alt+A           Aktive patienter


Alt+J / Alt+N   Notater

  Alt+C           Nyt notat
  
  Shift+Alt+C     Nyt grønt skema
  
  Alt+L           Sæt patient på liste


Alt+S           Svar

  Alt+M           MiBa


Alt+H           Vis genveje

Alt+H eller Esc lukker

# Installation
1. Create a bookmark to consume (doesn't matter for what)
2. Go to lims-keyboard-layer-bookmarlet.js
3. Copy the full code
4. Edit the bookmark from step 1, put the code from step 3 in the URL field, Give it a name, like ⌨️ wwBakt ⌨️
5. Save

# Use
Click the bookmarklet after logging in to wwbakt. Succesful loading will provide a small toast message, press Alt+H to see available shortcuts
